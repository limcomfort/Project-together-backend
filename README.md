Учебный бэкенд — аналог Twitter на Node.js + Express + TypeScript.

## Стек
- Node.js + Express
- TypeScript (tsx)
- MongoDB (Mongoose)
- cors, dotenv

## Установка
```bash
npm install
cp .env.example .env
```

## Запуск
```bash
npm run dev
```

Сервер запустится на http://localhost:5000.

## API

| Метод  | Путь              | Описание       |
|--------|-------------------|----------------|
| GET    | /api/posts        | Список постов  |
| GET    | /api/posts/:id    | Один пост      |
| POST   | /api/posts        | Создать пост   |
| DELETE | /api/posts/:id    | Удалить пост   |
